# 模型和时间评估方法

[中文](methods.zh.md) · [English](methods.en.md) · [完整结果](results.zh.md)

## 目标与信息集

城市c的目标月记为m，输入月t=m-1。目标为 $y_{c,m}=I^{new}_{c,m}-100$，即下一统计月新房价格指数环比变化。输入最多读取已公布的t月数据。在t月月报公布后执行预测，通常已进入m月中旬。

首个完整输入窗口为2021年5月至11月，首个标签月2021年12月。训练标签共有50个月；2026年2月只有预测，没有实际标签。

## 特征和信息对照

| 输入 | 数量 | 定义 |
| --- | ---: | --- |
| 当前值 | 2 | 本城t月新房、二手房环比 |
| 同期面板统计 | 3 | 70城等权新房均值、二手房均值、新房上涨城市比例 |
| 周期 | 2 | 输入月份的sin与cos编码 |
| 滞后值 | 8 | 两通道各lag1/2/3/6 |
| 滚动均值 | 4 | 两通道各3月、6月均值，包含当前月 |

共19项数值特征。Ridge另有70维城市独热编码；神经模型另有4维城市嵌入和七个月原始双通道序列，覆盖t-6至t。因此神经网络覆盖Ridge的lag6及全部显式上下文，但两个模型的输入参数化不同，网络还读取完整窗口的原始值。

原六个月原型仅覆盖t-5至t；新版本同时改变窗口和上下文预测头。0.2951到0.2791的三种子验证变化反映整个配置变化，不能只归因于多加一个月份。

### 特征列与样本对齐

特征按[特征构造函数build_dataset()](../research/train_forecast.py)的顺序构造，并写入[权重元数据](../research/results/research/model_metadata.json)：

| 分组 | 实际列名（组内顺序） |
| --- | --- |
| 当前值 | `new_mom_pct`、`second_mom_pct` |
| 面板背景 | `national_new_mean`、`national_second_mean`、`share_cities_rising` |
| 周期 | `calendar_sin`、`calendar_cos` |
| 新房滞后 | `new_lag1`、`new_lag2`、`new_lag3`、`new_lag6` |
| 二手房滞后 | `second_lag1`、`second_lag2`、`second_lag3`、`second_lag6` |
| 均值 | `new_mean3`、`new_mean6`、`second_mean3`、`second_mean6` |

均值包含输入月t；周期编码为输入月份编号q的sin(2πq/12)、cos(2πq/12)。样本标签在每城序列内向下一月移动，来源URL一起对齐。

| 样本用途 | 已知输入窗口 | 对应标签 / 预测月 |
| --- | --- | --- |
| 首个监督样本 | 2021-05…2021-11 | 2021-12 |
| 预测2025-01时最后一个训练样本 | 2024-05…2024-11 | 2024-12，已公布 |
| 2025-01回顾性预测 | 2024-06…2024-12 | 2025-01，预测时未读 |
| 最终截点预测 | 2025-07…2026-01 | 2026-02，无实际标签 |

模型每次使用目标月早于当前预测月的全部监督样本。标签月2021-12起计：2024-01初次拟合25个月，2025-01拟合37个月，2026-01拟合49个月，2026-02拟合50个月；每月每城一条。每个起点重新拟合标准化和模型，神经模型重新初始化，不继承上一月网络权重。

### 主模型与非神经对照

Ridge将19项数值特征按训练样本做`StandardScaler`标准化，再拼接70维城市独热编码，得到89列。带截距的目标函数为：

$$
\min_{w,b}\sum_{(c,j)\in \mathcal T_m}
(y_{c,j}-b-z_{c,j}^{\mathsf T}w)^2+\alpha\lVert w\rVert_2^2,
\qquad \mathcal T_m=\{(c,j):c=1,\ldots,70,\ j\in\mathcal M_m\}.
$$

这里 $\mathcal M_m$ 为2021-12起、早于m的已知训练标签月份集合。α筛选5、25、100，最终主模型为25。系数同时作用于标准化数值列和城市独热列，城市列也受到L2正则。沿用上月预测为 $\hat y_{c,m}=y_{c,m-1}$，没有训练参数。

梯度提升树使用19项原尺度特征和70维城市编码：`HistGradientBoostingRegressor`、120次迭代、学习率0.05、最大叶节点7或15、最小叶样本30、L2=0.5、关闭早停、random_state=42。

## 上下文时序网络

![网络结构](figures/zh/03_architecture.png)

| 模块 | 运算 | 输出形状或参数 |
| --- | --- | --- |
| 双通道序列 | 按过去训练窗口计算通道标准化 | B×70×7×2 |
| 第一层卷积 | Conv1d 2→12，kernel3，padding1，ReLU | 每城12×7 |
| 第二层卷积 | Conv1d 12→12，kernel3，padding1，ReLU | 每城12×7 |
| 时间池化 | 时间维均值 | 每城12维 |
| 上下文 | 拼接19项标准化特征与4维城市嵌入 | 每城35维 |
| 预测头 | Linear35→24，ReLU，Dropout0.15，Linear24→1 | 修正量δ |
| 输出 | $\hat y_{c,m}=y_{c,t}+\delta_{c,m}$ | 每城一个变化预测 |

参数数目：城市嵌入280、两层卷积84与444、预测头864与25，共1697。输出层零初始化。网络不使用膨胀卷积或Transformer。

B表示目标月份数。实现将输入重排为(B×70)×2×7，再逐城应用同一组卷积；对称padding只作用于已知窗口内。时间池化后恢复B×70×12。城市特征之间通过已知面板均值/上涨比例提供背景，当前卷积结构没有城市图消息传递。

序列标准化的每通道均值、标准差在训练输入窗口的月×城×位置上统计，标准差下限0.05；重叠窗口按其实际出现次数参与统计。19项数值列另用训练行的`StandardScaler`。当前预测窗口只应用这些统计量。保存权重推理同时加载`preprocessing.npz`与城市/特征顺序元数据。

所有神经模型：AdamW学习率0.006、权重衰减0.02；梯度裁剪1；每个滚动起点固定60轮，不用目标月标签早停。每轮在全部过去训练月×70城上完成一次梯度更新。筛选种子13/31/47，最终神经与方向代表增加61/79，推理关闭Dropout并取预测均值。种子MAE标准差是重复训练描述量，不是时间采样置信区间。

基础回归使用PyTorch `smooth_l1_loss`，β=0.25，误差e为预测−实际。其损失形式及归约为：

$$
\ell_\beta(e)=
\begin{cases}
e^2/(2\beta), & |e|<\beta,\\
|e|-\beta/2, & |e|\ge\beta,
\end{cases}
\qquad
L_{\mathrm{city}}=\frac1{70|\mathcal M_m|}
\sum_{j\in\mathcal M_m}\sum_{c=1}^{70}\ell_\beta(\hat y_{c,j}-y_{c,j}).
$$

这里 $\mathcal M_m$ 为暖启动后、早于m的已知训练标签月份集合。误差、β及输出修正量均使用环比百分点尺度。零初始化输出层使初始修正为0，损失在最终预测值上计算。

## 独立结构消融

### 窗口归一化

检验各城窗口的水平和波动尺度差异是否影响拟合。

参考[RevIN作者实现](https://github.com/ts-kim/RevIN)，在每城每通道的已知七个月窗口计算均值μ与标准差σ，关闭可学习仿射，σ下限0.05。序列输入为 $(x-\mu)/\sigma$，新房输出修正量乘新房σ后加到原尺度上一期变化。两个输入通道只有一个输出通道，不能把二手房统计量用于还原新房输出。19项上下文保持相同。

### 过去误差校正

以逐月Ridge alpha25为基础。预测m月先使用过去状态：

$$
\hat y^{corr}_{c,m}=\hat y^{\mathrm{Ridge}}_{c,m}-\lambda b_{m-1}.
$$

m月实际值公布后，以**未经校正的Ridge预测**计算 $e_m=\frac1{70}\sum_c(\hat y^{\mathrm{Ridge}}_{c,m}-y_{c,m})$，更新 $b_m=\rho b_{m-1}+(1-\rho)e_m$，供m+1月使用。

rho取0.5/0.8，lambda取0.5/1。状态2024年1月初始化为0；预测后才计算当前误差，并传到2025与最终预测。状态来自过去滚动样本外预测，不来自训练拟合残差。

### 市场与城市分解

检验将共同市场变化与城市偏离分开学习是否改善预测。

训练月份定义 $g_m=\frac1{70}\sum_c y_{c,m}$、$r_{c,m}=y_{c,m}-g_m$。输出 $\hat y_{c,m}=\hat g_m+\hat r_{c,m}$，残差预测减去其70城均值，使预测残差均值为0。预测阶段使用预测g，不用目标月真实g。

市场分支输入17维：双通道七个月等权均值序列14项、上涨城市比例1项、周期2项。网络分支为17→12→1；训练损失为城市最终输出Huber加0.25×市场均值Huber。线性对照两个Ridge均固定alpha25，市场标签每月一条，不重复70次。

这里的市场均值是面板统计量，不是国家统计局官方全国指数。

### 方向辅助任务

检验额外分类约束与类别加权对上涨识别和幅度误差的影响。

未归一化双分支网络增加共享24维表示的三分类头，预测下跌/持平/上涨。训练标签按实际环比小于0、等于0、大于0确定。损失额外加入eta×交叉熵，eta为0.01/0.05。类别权重选择无权重或过去训练频率的逆平方根，先截到最大3，再归一到训练标签平均权重1。

分类概率不修改回归预测。回归三类判断持平区间固定±0.05；二元上涨判断为>0，平衡准确率排除实际持平。分类头和回归方向分别评分，并报告不一致比例。

### 线性对照与组合

NLinear形式参考[AAAI2023作者实现](https://github.com/cure-lab/LTSF-Linear)：标准化序列各通道减其窗口末值，展平14项、拼接19项特征与4维嵌入，通过单一线性输出层预测修正量，最后加回原尺度新房末值。共318参数，是加入上下文的短序列适配。

在线组合参考[OneNet研究方向](https://proceedings.neurips.cc/paper_files/paper/2023/hash/dd6a47bc0aad6f34aa5e77706d90cdc4-Abstract-Conference.html)，独立实现EWMA加softmax，不复现论文的强化学习机制。专家为验证最好的简单基线、三种子选出的非线性网络及沿用上月。风险更新为 $R_m=0.5R_{m-1}+0.5MAE_m$，预测前权重 $w_m=softmax(-R_{m-1}/0.02)$。另做均匀权重对照。

## 选择与评估

![时间协议](figures/zh/02_protocol.png)

候选清单写入[锁定配置](../research/results/research/locked_experiment_registry.json)，20个单模型及2种组合，没有按后期得分追加模型。全部单模型在2024滚动验证；代表模型在后期评分前写入[选择记录](../research/results/research/selection_before_retrospective.json)。

替换主模型门槛：2024总体MAE降低≥3%，至少8个月胜过最优简单基线，任一半年误差恶化≤5%。方向门槛：相对未归一化双分支网络，整体MAE恶化≤2%，涨跌平衡准确率提高≥0.05，上涨MAE下降≥10%。这些是工程筛选门槛，不是显著性的定义。

五种子最终复核不用于更早季度选择。季度检查使用原始三种子记录，只从前3/6/9个月决定后续季度的配置与专家。组合全年验证得分使用全年选出的专家，存在额外选择不确定性。

后期评估按月份保留全部70城。统计区间使用连续三个月循环区块、20000次重采样，配对比较同月MAE。区间未校正研究者已看后期、配置筛选或潜在官方修订。2026年1月基期与权数调整，单独报告2025全年与2026年1月。

### 指标口径

预测月集合为 $\mathcal E$，总体MAE为 $\frac1{70|\mathcal E|}\sum_{m\in\mathcal E}\sum_c|\hat y_{c,m}-y_{c,m}|$。每月均为70城，因此也等于各月MAE的等权平均。RMSE是均方误差的平方根；有符号偏差是预测−实际的均值。上涨/下跌MAE只在实际>0/<0的对应记录上计算。

二元平衡准确率为上涨召回率与下跌样本判为非上涨的比例的平均；实际0值排除。幅度、分类头和回归方向各自单独评分。总体MAE、分组误差、逐月稳定性与配对区间同时报告，主模型选择仅使用2024记录。
